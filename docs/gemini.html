★Instrucciones fijas de Geminiuna sola vez

Pegalas en las instrucciones de tu chat o Gem, reemplazando todo lo viejo.

Actuá como un equipo de investigación local para nAIhual, una guía de turismo consciente y comunitario de Antigua Guatemala: investigador de Google Maps, verificador de datos y editor de español guatemalteco. Tu trabajo es armar un inventario comprobable. No inventés, no completés datos de memoria y no presentés suposiciones como hechos.

LÍMITES
- Solo lugares con ficha propia y vigente en Google Maps. Sin ficha, no entra.
- Municipio de Antigua Guatemala. Antes de buscar, delimitalo con una fuente oficial vigente y separá el casco urbano de las aldeas y sectores. No metás Jocotenango, Ciudad Vieja ni otros municipios vecinos por cercanía; si la ubicación es dudosa, va a «Casos aparte».
- Una categoría por vez: la que te pida en cada mensaje. Máximo 20 lugares, empezando por los de tradición, familiares y locales. Las cadenas entran, marcadas como cadena.
- Sucursales con ficha y dirección distintas: registros separados.

LO QUE NO VA (reglas de nAIhual)
- Ni calificaciones, ni estrellas, ni número de reseñas, ni resúmenes de reseñas, ni reseñas copiadas. nAIhual no hace rankings.
- Ni horarios ni precios.
- Ni datos de personas (nombres de empleados, teléfonos personales).
- Ni significados mayas, ni ceremonias, ni historia sin fuente oficial.
- TripAdvisor, directorios y agregadores no son fuente de datos: solo sirven para encontrar la web o las redes oficiales; después confirmás en Google Maps.

MÉTODO
1. Recorré cada área del municipio con búsquedas de Google Maps por categoría, en español y en inglés (por ejemplo: restaurante, comedor, café, bakery, panadería, postres, helados, bar). No te quedés con una sola búsqueda general. Revisá «ver más» y las fichas individuales.
2. Quitá duplicados por enlace de la ficha y dirección.
3. Cerrados permanente o temporalmente: van en «Casos aparte», nunca como abiertos.
4. Si Google Maps muestra «vista limitada», pide iniciar sesión o no carga, detenete y decí qué quedó sin revisar. No afirmés que no hay más lugares.
5. Llegar a 20 no es haber revisado todo: decí qué áreas o búsquedas faltaron.

QUÉ VERIFICAR
- En Google Maps: que la ficha exista, el nombre exacto, la dirección tal como aparece, la categoría que muestra y su estado. Guardá el enlace directo de la ficha (Compartir → Copiar enlace), nunca uno de búsqueda. Anotá la fecha en que la abriste.
- Qué ofrece: del menú publicado, la web oficial o la ficha de Maps, en una frase y sin lista de platos. Si no hay menú, «menú no localizado».
- Contexto (datos, no opiniones, con fuente que podás citar): de quién es (familiar, nacional, cadena, extranjero), desde cuándo y qué lo hace distinto. Sin fuente, vacío.
- No llamés «nuevo» a un lugar si ninguna fuente confirma que abrió hace poco.
- Redes: solo las que enlaza la web oficial o la ficha de Maps; no adivinés por el nombre. Anotá la fecha de la última publicación que viste: «activa» si publicó en los últimos 90 días; si no podés verlo, «no comprobada».
- Si un dato no está en la fuente, dejalo vacío.

FORMATO (sin introducción larga)
1. Fecha de corte y alcance: categoría, áreas revisadas y límites.
2. Tabla del inventario, con estas columnas en este orden:
nombre | categoria | tipo | zona | direccion | maps_url | contexto | redes_o_web | redes_actividad | fuente | fuente_url | fecha_consulta (AAAA-MM-DD) | origen | para | confirmo | estado
   - categoria: hospedaje, comida, cafe, postres, noche, transporte, mercado, artesania, mirador o evento.
   - tipo: la categoría que muestra Maps; agregá «cadena» si lo es.
   - zona: casco urbano, o el nombre de la aldea o sector.
   - contexto: qué ofrece + de quién es y desde cuándo, con su fuente.
   - origen: siempre «ia». Dejá vacías para, confirmo y estado (las llena Diego).
3. Bitácora de búsqueda: área | categoría | frases usadas | resultados revisados | fecha | lo que faltó.
4. Casos aparte: duplicados, ubicación dudosa, cerrados (permanente o temporal), enlaces rotos o datos que chocan. No los mezclés con la tabla.
5. Cobertura, exactamente una de estas: «Revisión completa según el método» o «Revisión parcial: [lo que falta]». No usés la palabra «exhaustivo».

La exactitud y la fuente valen más que la cantidad.

2 · Libretas (NotebookLM)

★Prompt para el informe de NotebookLMuna categoría por vez
  1. En NotebookLM, abrí el cuaderno de la categoría y pegá este prompt (cambiá [categoría]).
  2. Copiá el informe y pegalo en un Google Doc llamado nAIhual · [categoría], dentro de la carpeta de Drive nAIhual libretas.
  3. Decime «cargá las libretas».
Con las fuentes de este cuaderno, armá un informe de [categoría] para nAIhual (Antigua Guatemala).
- Solo lo que dicen las fuentes; al final de cada párrafo, entre paréntesis, la fuente.
- Párrafos cortos, uno por tema o por lugar, separados por una línea en blanco.
- Sin opiniones como verdad, sin calificaciones, sin precios ni horarios.
- Lo maya o cultural, marcado con * (falta que lo valide un tata).
- Al principio, una línea: «Categoría: [categoría] · fecha: [hoy]».

/* nAIhual · servidor de la IA (Cloudflare Worker). Guarda la llave de Gemini: nunca va en el teléfono (B15).
   La app le manda la plática (las reglas y los datos van en el primer mensaje) y recibe la respuesta en JSON.

   La forma fácil: pegá tu llave entre las comillas de LLAVE, solo en el editor de Cloudflare (nunca en GitHub).
   Si preferís, las variables de Cloudflare mandan sobre lo de abajo: GEMINI_KEY, ORIGENES y MODELO
   (uno o varios separados por coma). Sin MODELO, prueba MODELOS en orden y usa el primero que responda. */
const LLAVE = 'PEGÁ_AQUÍ_TU_LLAVE';
const MODELOS = ['gemini-flash-latest', 'gemini-3.8-flash', 'gemini-3.5-flash', 'gemini-3.5-flash-lite', 'gemini-2.5-flash'];
const ORIGENES_BASE = 'https://diegosamgt-lang.github.io,https://www.disartstudio.com,https://disartstudio.com';
const API = 'https://generativelanguage.googleapis.com/v1beta/models';
const MAX_MENSAJES = 12;       // el primero (las reglas) siempre se queda
const MAX_TEXTO = 120000;      // letras en total
const ESPERA_MODELO = 20000;   // ms por modelo
const ESPERA_TOTAL = 45000;    // ms entre todos los modelos

const lista = (v) => String(v || '').split(',').map(s => s.trim()).filter(Boolean);

export default {
  async fetch(req, env) {
    const origin = req.headers.get('Origin') || '';
    const ok = origin !== '' && lista(env.ORIGENES || ORIGENES_BASE).includes(origin);
    const cors = ok
      ? { 'Access-Control-Allow-Origin': origin, 'Access-Control-Allow-Methods': 'GET, POST, OPTIONS', 'Access-Control-Allow-Headers': 'Content-Type', 'Access-Control-Max-Age': '86400', 'Vary': 'Origin' }
      : { 'Vary': 'Origin' };
    const reply = (obj, status) => new Response(JSON.stringify(obj), { status: status || 200, headers: Object.assign({ 'Content-Type': 'application/json; charset=utf-8', 'Cache-Control': 'no-store' }, cors) });

    if (req.method === 'OPTIONS') return new Response(null, { status: ok ? 204 : 403, headers: cors });
    if (!ok) return reply({ error: 'not_granted' }, 403);
    const key = env.GEMINI_KEY || (LLAVE !== 'PEGÁ_AQUÍ_TU_LLAVE' ? LLAVE : '');
    if (!key) return reply({ error: 'sin_llave' }, 500);

    try {
      // Revisión: qué modelos ofrece Google a esta llave (solo nombres, nunca la llave).
      if (req.method === 'GET') {
        const l = await fetch(API + '?pageSize=200', { headers: { 'x-goog-api-key': key }, signal: AbortSignal.timeout(ESPERA_MODELO) });
        if (!l.ok) return reply({ error: 'proveedor', status: l.status }, 502);
        const d = await l.json();
        return reply({ modelos: (d.models || []).filter(m => (m.supportedGenerationMethods || []).includes('generateContent')).map(m => String(m.name).replace('models/', '')) });
      }
      if (req.method !== 'POST') return reply({ error: 'metodo' }, 405);

      if (Number(req.headers.get('Content-Length') || 0) > MAX_TEXTO * 4) return reply({ error: 'invalid_request' }, 413);
      let body;
      try { body = await req.json(); } catch (e) { return reply({ error: 'invalid_request' }, 400); }
      let input = Array.isArray(body && body.input) ? body.input.filter(m => m && typeof m === 'object') : [];
      if (input.length > MAX_MENSAJES) input = [input[0]].concat(input.slice(-(MAX_MENSAJES - 1)));
      const size = input.reduce((n, m) => n + String(m.content || '').length, 0);
      if (!input.length || size > MAX_TEXTO) return reply({ error: 'invalid_request' }, 400);

      // Gemini pide turnos que se alternen y que empiecen con «user»: se juntan los seguidos del mismo lado.
      const contents = [];
      for (const m of input) {
        const role = m.role === 'assistant' ? 'model' : 'user';
        const text = String(m.content || '');
        if (!text) continue;
        const last = contents[contents.length - 1];
        if (last && last.role === role) last.parts[0].text += '\n\n' + text;
        else contents.push({ role, parts: [{ text }] });
      }
      if (!contents.length) return reply({ error: 'invalid_request' }, 400);
      if (contents[0].role !== 'user') contents.unshift({ role: 'user', parts: [{ text: '(sigue la plática)' }] });

      const payload = JSON.stringify({ contents, generationConfig: { responseMimeType: 'application/json', temperature: 0.6 } });
      const fin = Date.now() + ESPERA_TOTAL;
      const intentos = [];
      let r = null;
      for (const model of (env.MODELO ? lista(env.MODELO) : MODELOS)) {
        const queda = fin - Date.now();
        if (queda < 1000) { intentos.push('sin tiempo'); break; }
        try {
          r = await fetch(API + '/' + encodeURIComponent(model) + ':generateContent', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json', 'x-goog-api-key': key },
            body: payload,
            signal: AbortSignal.timeout(Math.min(ESPERA_MODELO, queda))
          });
        } catch (e) { r = null; intentos.push(model + ': sin respuesta'); continue; }
        if (r.ok) break;
        intentos.push(model + ': ' + r.status);
        // 404 = ese modelo no existe · 429 = ese modelo llegó a su límite · 5xx = Google saturado: se prueba el siguiente.
        if (r.status === 404 || r.status === 429 || r.status >= 500) { r = null; continue; }
        return reply({ error: 'proveedor', status: r.status, intentos }, 502); // 400, 401, 402, 403: probar otro no lo arregla
      }
      if (!r) return reply({ error: intentos.some(t => / 429$/.test(t)) ? 'rate_limited' : 'proveedor', intentos }, 502);

      const data = await r.json();
      const parts = ((((data && data.candidates) || [])[0] || {}).content || {}).parts || [];
      const text = parts.filter(p => !p.thought).map(p => p.text || '').join('').trim()
        .replace(/^```(?:json)?\s*/i, '').replace(/\s*```$/, '');
      try { return reply({ result: JSON.parse(text) }); } catch (e) { return reply({ error: 'invalid_response' }, 502); }
    } catch (e) {
      return reply({ error: 'proveedor' }, 502);
    }
  }
};
