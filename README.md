# nAIhual

**nAIhual** es un agente artesanal turístico-cultural: un puente entre viajeros y las comunidades, la cultura y el territorio de Guatemala. *Viaja directo a la raíz.*

- **App:** `app/index.html`. Se abre directo en el navegador.
- **Todo el proyecto en un solo documento:** `docs/nAIhual.md`. Ahí están el concepto, los guardianes, los circuitos, las fuentes, las decisiones y el historial.
- **Método de trabajo:** `0_PROMPT_MAESTRO.md` a `4_LECCIONES.md`.
- **Fuentes:** los dos PDF de esta carpeta.
- **Versiones anteriores:** `versiones/`.
